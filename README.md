# MAKAF ARCHITECTS — Website Package

## Structure

- `index.html` — page structure/content
- `style.css` — all website styling and responsive layout
- `script.js` — navigation, modal, WhatsApp contact flow, scroll reveals
- `assets/logo.svg` — custom MAKAF ARCHITECTS wordmark/monogram
- `assets/favicon.svg` — favicon
- `assets/images/` — individual, full-resolution generated architectural photographs used by the website

## Notes

The eight photography files are stored separately, and each of the eight is used once in the website. They are presentation visuals created for the concept and should be replaced with the studio's own project photography/renders before representing them as completed MAKAF projects.

The contact form prepares a WhatsApp message using the phone number supplied in the provided profile screenshot. No form data is stored by the static website.

No backend, CMS, database, or server-side form processing is included.
